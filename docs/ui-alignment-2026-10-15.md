# SciZhi 双端界面：实施与验收

实现范围为 Flet 桌面与 OpenTUI 终端。保留科研工作流、会话、权限与审批语义，在现有渲染框架中对齐字体层级、主题、设置与交互。

## 可用功能

- `assets/ui-design.json` 是偏好、字号角色、间距、圆角和动效时长的共享定义；Python 与 JavaScript 读取同一文件。
- 旧深色开关、字号比例、密度和检查器偏好可迁移。单项保存不覆盖其他设置。
- 桌面界面基准 14px，可设 12–20px；代码及内置终端字号独立，中文字体回退保留。
- 跟随系统、浅色与深色主题；输入、菜单、弹窗、抽屉、代码预览随主题更新。
- 设置中心按界面、代码与终端、显示与交互分组。数字输入按 Enter 或失焦保存，错误提示保留草稿。
- 项目文件与 Git 差异预览支持独立代码配色、行号和换行。关闭换行后桌面可水平滚动；TUI 超长行用省略提示。
- 桌面窄窗显示导航抽屉；TUI 使用 Ctrl+B 开关停靠/浮层侧栏，Esc 关闭并保留输入。
- 外观修改可跨端自动同步，未提交字号草稿不会被覆盖。停用动效后保留静态忙碌状态。
- TUI 的实际字体与字号仍由终端宿主控制；`/config` 中桌面字号项明确标注适用端。

## 本次完善

- 保留用户的圆角调整，统一输入、卡片、项目、会话和弹窗的几何层级。
- 会话、历史、侧边讨论、项目 Markdown 和科研成果中的顶层围栏代码块复用代码预览。代码字号、主题、行号和换行设置同步生效；列表或引用内的嵌套代码继续采用原生 Markdown，保留原文结构，嵌套行号和换行尚不单独控制。
- 流式回复不重建未变的代码块，重复外观刷新保留控件身份与选区。
- 审批 diff 使用相同显示设置，已打开的审批弹窗也跟随外部设置变化。非法行区间、空替换和非唯一匹配明确提示；超过 260 行的差异注明省略。
- 关闭动效后，数据分析和系统自检显示静态等待图标；反馈与面板时长使用共享定义。
- TUI 长消息完整换行，保留中文、组合字符与制表符内容；关闭代码换行时才使用省略显示。
- TUI 快捷键提示保留实际 Control 绑定；修复双击 Ctrl+C 退出及中间继续输入时的退出预警取消。
- 命令面板按终端高度缩减可见候选，键盘选中项始终位于窗口内；54×18 下保留输入区，禁用原因也受行宽限制。
- 上下文用量读取当前会话估算，未知状态显示「暂无数据」，切换会话后旧响应不覆盖当前统计。
- 研究包配置快照递归脱敏，包括模型连接密钥与旧端点 URL 中的凭据，导出不修改运行配置。
- Windows 文件分页缓存结合文件变更日志序列判断失效，避免快速同大小修改与恢复时间戳造成旧结果复用；无法取得可靠标记时重新扫描文件。
- 代码注释改为功能、行为和边界说明；设计参考集中保留在 DESIGN.md，许可与第三方归属保持完整。

## 使用

从项目根目录启动：

```powershell
python scripts/gezhi.py desktop
npm --prefix tui start
```

本轮交付为源码；`dist/` 中既有安装包未重新构建。ZCode 参考源码、运行数据、截图和测试缓存不纳入发布源码。
