# 双端 UI 对标 ZCode：实施与验收

实现范围为 Flet 桌面与 OpenTUI 终端。保留科研工作流、会话、权限与审批语义，在现有渲染框架中对齐字体层级、主题、设置与交互。

## 可用功能

- `assets/ui-design.json` 是偏好、字号角色、间距、圆角和动效时长的共享定义；Python 与 JavaScript 读取同一文件。
- 旧深色开关、字号比例、密度和检查器偏好可迁移。单项保存不覆盖其他设置。
- 桌面界面基准 14px，可设 12–20px；代码及内置终端字号独立，中文字体回退保留。
- 跟随系统、浅色与深色主题；输入、菜单、弹窗、抽屉、代码预览随主题更新。
- 设置中心按界面、代码与终端、显示与交互分组。数字输入按 Enter 或失焦保存，错误提示保留草稿。
- 项目文件与 Git 差异预览支持独立代码配色、行号和换行。关闭换行后桌面可水平滚动；TUI 超长行用省略提示。
- 桌面窄窗显示导航抽屉；TUI 使用 Ctrl+B 开关停靠/浮层侧栏，Esc 关闭并保留输入。
- 外观修改可跨端自动同步，未提交字号草稿不会被覆盖。停用动效后保留静态忙碌状态。
- TUI 的实际字体与字号仍由终端宿主控制；`/config` 中桌面字号项明确标注适用端。

## 使用

从项目根目录启动：

```powershell
python scripts/gezhi.py desktop
npm --prefix tui start
```

本轮交付为源码；`dist/` 中既有安装包未重新构建。ZCode 参考源码、运行数据、截图和测试缓存不纳入发布源码。
