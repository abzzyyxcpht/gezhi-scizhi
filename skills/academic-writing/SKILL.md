# 学术写作规范

- 结论句必须可回溯到文献池材料；禁止出现材料之外的数字、实验结果与"据我所知"式论断。
- 时态：转述他人工作用过去时（提出了/发现了），陈述领域公认事实用现在时。
- 术语：同一概念全篇使用同一译名，首次出现附英文原文，如「检索增强生成（RAG）」；以用户 GEZHI.md 术语表为最高优先。
- 对比表述优先给出可核查的量化差异，禁止"明显更好"这类无依据形容。
- 每段以主题句开头，段落 3–6 句；连接词（然而/因此/此外）每段至多一次。
- 引用纪律：每个论点后必须挂支撑文献锚点；没有锚点的句子宁可删除。
