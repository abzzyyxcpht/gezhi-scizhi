# 实验设计与复核

- 给出可证伪假设、主要指标、合理基线、数据划分、消融和失败条件；未执行的实验清楚标为计划。
- 检查训练、验证、测试划分是否泄漏，同一主体或时间相关样本是否需分组隔离。
- 数值来自真实工具输出；保留输入文件哈希、代码与环境版本、命令、随机种子和运行记录。
- 区分标准差、标准误与置信区间，说明变异来自种子、划分还是样本；缺重复运行不能声称稳健。
- 相关性不推出因果，描述统计不自动推出显著性；检验方法需匹配设计与假设。
- 比较方法前核对数据集、指标定义、计算预算与评测条件；不可比结果不合并排名。
- 复核只覆盖已执行且有原始结果的部分，列出未核验内容与需要补跑的实验。
